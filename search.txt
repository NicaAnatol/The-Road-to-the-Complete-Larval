Review question
How has research on the larval Drosophila melanogaster connectome developed, and which datasets and computational methods are reported?

Analysis scope
Publication years analyzed: 2015-2024 inclusive
Original Scopus API filter: 2010-2026 inclusive
The 2015-2024 counts are a retrospective filter of the existing exports, not a new database search.
Scopus API search date recorded in the local search log: 2026-11-04
Web of Science was searched directly on its website. Its exact search date and query history were not retained.

Boolean search blocks
The following are the core Boolean expressions without database field wrappers or year filters. OR combines synonyms within a concept; AND combines organism, life stage, and connectivity/method concepts.

Query 1
(drosophila OR "fruit fly" OR "fly") AND (larva* OR larval) AND (connectom* OR "wiring diagram" OR "synaptic connectivity")

Query 2
drosophila AND (larva* OR larval) AND ("electron microscopy" OR "serial section*" OR "volume EM" OR "neuron reconstruction" OR "circuit reconstruction")

Query 3
drosophila AND (larva* OR larval) AND ("neural circuit*" OR "neuronal circuit*") AND (connectom* OR "electron microscop*")

Scopus API mapping and run
The generic Boolean expressions were mapped to the Scopus Search API using its TITLE-ABS-KEY field syntax and the original 2010-2026 publication-year filter. The query strings and result counts are listed in search_runs.csv. The current scopus search script keeps QUERIES as the field-neutral expressions and applies the Scopus wrapper and year filter at request time.

Web of Science mapping and exports
The query blocks were searched directly on the Web of Science website, as reported by the researcher. The downloaded savedrecs (7).xls, savedrecs (8).xls, and savedrecs (9).xls files are the WoS exports used in the merge. The downloaded records were filtered to 2015-2024 for the counts in source_counts.csv. The exact WoS interface settings and search date should be added from the original browser/search history if available.

Abstract handling
The Scopus Search API export contains incomplete abstract coverage. In the 2015-2024 Scopus export, 269 of 340 rows have an abstract and 71 do not. Missing abstracts were manually looked up where accessible, as reported by the researcher. The local database also shows an OpenAlex enrichment check for all 488 Scopus records, but per-record abstract provenance was not preserved; therefore the number of abstracts obtained manually cannot be separated from other enrichment in the merged files. The final merged screening set has 343 abstracts among 384 unique records.

Screening and deduplication
The analysis script imports the three WoS exports and Scopus CSV, then checks duplicate-log identifiers against the source exports. Deduplication used DOI, then normalized title and year when DOI matching was unavailable. The 2015-2024 source, duplicate, and retained counts are in source_counts.csv.

Title/abstract screening was performed in ASReview LAB across 554 deduplicated records: 32 marked relevant, 507 excluded with a recorded reason, and 15 unclear. In the 2015-2024 subset the labels are 21, 354, and 9 respectively. Full-text eligibility review is still pending. The concise files asreview_included.csv, asreview_excluded.csv, and asreview_unclear.csv contain identifiers, titles, years, DOIs, labels, and recorded rationales; abstracts are omitted. Eligibility rules are in screening_criteria.csv.

Controlled vocabulary and limits
Candidate terms should be checked against IEEE Taxonomy, ACM CCS, Scopus indexed terms, and WoS Keywords Plus before rerunning. The original broad term "fly" may retrieve unrelated records and should be evaluated during query refinement. Search dates, exact WoS query history, and per-record abstract provenance are not available in the retained exports.
